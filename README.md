## 🚀 Proyectos Destacados

### ✈️ Portal del Tripulante — Air Europa
Aplicación web corporativa utilizada por toda la plantilla de vuelo de Air Europa para consulta de programación de vuelos, vacaciones y servicios internos. Arquitectura de microservicios con Node.js y Angular.

### 🔗 API de Instrucción de Tripulantes
Diseño y desarrollo de API pública como núcleo de integración con 2 proveedores externos, cubriendo el módulo completo de instrucción de tripulantes de Air Europa.

### 📱 Plataforma de Apps Corporativas
Sistema de distribución y gestión de aplicaciones empresariales en iOS y Android para toda la organización.

### 🏢 ERP de Gestión de ERTEs COVID-19
Sistema crítico para el control y gestión de Expedientes de Regulación Temporal de Empleo de toda la tripulación de Air Europa durante la pandemia. Desplegado bajo alta presión y plazo reducido.

### 👨 Bolsa de Empleo de Pilotos
Desarrollo en VueJS de las plataformas de captación de pilotos para Air Europa y Air Europa Express.
